
Exemplo conceitual de agent_as_tool

agent_as_tool acontece quando um agente especializado é chamado por outro agente como se fosse uma ferramenta.

Exemplo

Um coordenador precisa responder uma pergunta complexa.

Ele pode chamar:

agente pesquisador;
agente de código;
agente crítico.

Cada agente funciona como uma ferramenta especializada, mas com capacidade própria de raciocínio.

Diferença para uma tool comum

Uma tool comum executa uma função específica.

Um agente usado como ferramenta pode interpretar a tarefa, tomar decisões internas e produzir uma resposta mais elaborada.
