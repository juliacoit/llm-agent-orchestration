
Exemplo conceitual de transfer_to_agent

O conceito de transfer_to_agent aparece quando um agente transfere a responsabilidade da tarefa para outro agente mais adequado.

Exemplo

Usuário:

"Crie um código em Python para calcular média."

Coordenador:

Essa tarefa é de programação. Vou transferir para o agente de código.

Agente de código:

Recebe a tarefa e gera a solução.

Fluxo
Usuário
  ↓
Coordenador
  ↓
Agente de Código
  ↓
Resposta final
