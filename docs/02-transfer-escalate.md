
transfer_to_agent e escalate
transfer_to_agent

transfer_to_agent representa a ideia de transferir uma tarefa de um agente para outro.

Isso acontece quando o agente atual identifica que outro agente é mais adequado para resolver o problema.

Exemplo

Um agente coordenador recebe:

"Crie uma função em Python para calcular média."

Ele pode transferir a tarefa para um agente especializado em código.

escalate

escalate representa a ideia de escalar o problema para um agente mais especializado, mais confiável ou de nível superior.

Isso é útil quando o agente atual não tem certeza, encontra uma limitação ou precisa de validação.

Exemplo

Um agente de atendimento recebe uma pergunta complexa sobre segurança. Em vez de responder sozinho, ele escala para um agente especialista.

Diferença geral
transfer_to_agent: encaminha para outro agente mais adequado.
escalate: encaminha para um nível superior ou mais especializado por limitação, risco ou incerteza.
