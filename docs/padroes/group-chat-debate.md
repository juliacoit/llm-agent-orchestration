# Group Chat / Debate

## Ideia principal

O padrão Group Chat ou Debate organiza agentes em uma conversa coletiva.

Cada agente pode ter uma perspectiva diferente e participar da discussão.

## Como funciona

1. O usuário envia uma pergunta.
2. Vários agentes discutem a questão.
3. Cada agente contribui com uma visão.
4. Um moderador ou coordenador consolida a resposta final.

## Exemplo

Pedido do usuário:

> "Qual estratégia uma startup deveria seguir para lançar um produto?"

Agentes possíveis:

- agente técnico;
- agente de marketing;
- agente financeiro;
- agente crítico;
- moderador.

## Vantagens

- Explora múltiplas perspectivas.
- Pode gerar respostas mais completas.
- Útil para problemas abertos.

## Desvantagens

- Pode ficar longo.
- Pode gerar repetição.
- Pode ser difícil controlar a discussão.

## Quando usar

Quando o problema se beneficia de diferentes pontos de vista ou debate entre especialistas.
