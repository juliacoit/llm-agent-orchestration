
tool vs agent_as_tool
Tool

Uma tool é uma função ou recurso específico que um agente pode chamar para realizar uma tarefa.

Exemplos:

calculadora;
busca na web;
consulta a banco de dados;
execução de código;
leitura de arquivo.

Uma tool normalmente executa uma ação bem definida.

Agent as Tool

agent_as_tool é a ideia de usar outro agente como se ele fosse uma ferramenta.

Nesse caso, o agente principal não chama apenas uma função simples. Ele chama outro agente, que pode ter instruções próprias, memória, ferramentas e comportamento especializado.

Exemplo

Um agente coordenador pode usar:

um agente de pesquisa como ferramenta;
um agente de código como ferramenta;
um agente crítico como ferramenta.
Diferença principal
ConceitoCaracterística
ToolFunção específica e geralmente determinística
Agent as ToolAgente especializado com raciocínio próprio
Quando usar cada um

Use uma tool quando a tarefa for simples e objetiva.

Use agent_as_tool quando a tarefa exigir interpretação, especialização ou múltiplos passos.
