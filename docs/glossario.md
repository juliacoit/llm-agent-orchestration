
Glossário
Agente

Componente baseado em LLM que pode receber instruções, tomar decisões e executar tarefas.

Roteador

Componente responsável por decidir qual agente, ferramenta ou fluxo deve ser acionado.

Tool

Função ou recurso específico usado por um agente.

Agent as Tool

Uso de um agente especializado como se ele fosse uma ferramenta chamada por outro agente.

Handoff

Transferência de responsabilidade de um agente para outro.

Orquestrador

Agente central responsável por coordenar outros agentes.

Worker

Agente especializado que executa uma subtarefa.

Critic

Agente responsável por revisar, avaliar ou criticar a saída de outro agente.

Blackboard

Espaço compartilhado onde agentes podem ler e escrever informações.

Multiagente

Sistema composto por múltiplos agentes colaborando para resolver uma tarefa.
